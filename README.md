# Stone-Dekor — строительство и ремонт

Сайт строительной компании **Stone Dekor** — строительство коттеджей, ремонт и отделка помещений.

## О проекте

Это веб-сайт для компании Stone Dekor, включающий:

- Главную страницу
- Галерею проектов
- Админку для управления контентом
- Страницу отзывов, интегрированную с социальными сетями
- Чатбот для обратной связи
